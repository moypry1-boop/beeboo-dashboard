# 🤖 بوت ديسكورد بلوحة تحكم — بستايل Wicks (يدعم 100 بوت!)

لوحة تحكم ويب عربية محمية بكلمة سر، تدير منها **حتى 100 بوت ديسكورد** وكل سيرفراتهم — كل حاجة من المتصفح.

## 🔐 الدخول

- اللوحة محمية **بكلمة سر** (وضع مالك — تحكم كامل).
- أول تشغيل: الكلمة الافتراضية `admin123` (أو اللي تكتبه في `ADMIN_PASSWORD` بالـ `.env`)
- غيّرها من الصفحة الرئيسية → "تغيير كلمة سر اللوحة" (مشفرة scrypt في قاعدة البيانات)
- بعد 5 محاولات غلط: قفل مؤقت 10 دقايق

## 🤖 نظام البوتات المتعددة

- من الصفحة الرئيسية: **إضافة بوت جديد** → الصق التوكن → يتشغل فوراً ✅
- لكل بوت صفحة سيرفراته، ولكل سيرفر لوحة إعدادات مستقلة
- الحد الأقصى: 100 بوت
- البوتات بتتفكر وتشتغل تلقائياً مع كل تشغيل للبرنامج
- تقدر تحذف أي بوت من اللوحة

## ✨ مميزات كل سيرفر (من اللوحة)

| القسم | التفاصيل |
|---|---|
| 🛡️ **الحماية** | منع لينكات · منع دعوات · كلمات ممنوعة · مضاد سبام · مضاد سبام منشن · حماية من الرايد + عقوبة لكل واحدة (مسح/إسكات/طرد/حظر) + قائمة بيضاء |
| 👋 **الترحيب** | رسالة Embed أو عادي + رسالة DM + رتبة تلقائية |
| 🚪 **المغادرة** | رسالة خروج |
| 📜 **السجلات** | رسائل · حظر/طرد · رتب وقنوات · ألقاب · دخول وخروج |
| 🔨 **الإشراف** | أوامر مباشرة على أي آي دي (حظر/طرد/إسكات/تحذير) + جدول تحذيرات |
| 🎫 **التذاكر** | لوحة بزرار "فتح تذكرة" + روم خاصة + زرار إغلاق + رتبة دعم |
| ⚡ **أوامر مخصصة** | حتى 50 أمر بريفيكس لكل سيرفر |

أوامر سلاش جاهزة: `/ban` `/kick` `/timeout` `/unban` `/clear` `/warn` `/warnings` `/help`

## 🚀 التشغيل

```bash
# 1) انسخ ملف البيئة وعدّله (اختياري — تقدر تظبط كل حاجة من اللوحة)
copy .env.example .env

# 2) ثبت وشغّل
npm install
npm start
```

افتح: **http://localhost:3000** → اكتب كلمة السر → **أضف توكن أول بوت** من الصفحة الرئيسية 🎉

> ⚠️ لكل بوت تضيفه: فعّل **Server Members Intent** + **Message Content Intent** من تبويب Bot في [الديفلوبر بورتال](https://discord.com/developers/applications)

### ضيف البوت لسيرفرك
من صفحة البوت → لو مش في سيرفرات هيظهرلك زرار الدعوة. أو استخدم:
```
https://discord.com/oauth2/authorize?client_id=BOT_ID&scope=bot%20applications.commands&permissions=8
```

## 📌 ملاحظات

- رتبة كل بوت لازم تكون فوق الرتب اللي بيتعامل معها.
- لو على استضافة: غيّر `BASE_URL` للدومين.
- البيانات في `data/db.json` — خد منه نسخة احتياطية (فيه البوتات والإعدادات وكلمة السر المشفرة).
- محتاج Node.js نسخة **18+**.
